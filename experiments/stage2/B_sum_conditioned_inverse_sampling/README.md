# Stage 2.B — SUM-Conditioned Inverse Sampling

Measures validity, valid-pair coverage, and distribution quality when only SUM
is clamped and both operands remain free. Questa wrappers and testbenches are in
`sim_scripts/stage2/B_sum_conditioned_inverse_sampling/`; the coupling sweep is
in `scripts/stage2/B_sum_conditioned_inverse_sampling/`.

Results are part of the consolidated Stage 2 benchmark report.
