# Stage 5.A — Adaptive Multibody Hamiltonian

Researches a 25-node, 6-bit least-plus-six-shadow adder with continuous
2/3/4-body Hamiltonian coefficients. Python tools live in
`scripts/stage5/A_adaptive_multibody_hamiltonian/`; the experiment log lives in
`results_and_reports/stage5/A_adaptive_multibody_hamiltonian/`.

The tracked graph-cut brainstorm and optimizer-formulation image are exploratory
research material. See the [Stage 5 overview](../README.md) for the full model,
commands, limitations, and current evidence.
