# Stage 5.B — RTL Handoff and Readiness Gate

RTL generation is blocked until Stage 5.A produces and freezes a concrete
zero-gap-violation solution JSON, term support, audit payload, and SHA-256
identity. No multibody term ROM or field core is claimed before that gate.

The intended follow-on uses Q3.29 coefficients first, bit-exact Python checks,
then Questa energy, local-field, and spin-update comparisons. Static gap closure
alone does not establish dynamic convergence improvement.
